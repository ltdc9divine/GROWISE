# GROWISE

Static website prototype for student startup marketing support.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server
and open the local address it provides. No build step, framework, or package
installation is required.

The site uses relative paths for `css/style.css` and the scripts in `js/`, so the
same files work when hosted from the project root on a static website.

Google Fonts are loaded from Google Fonts when an internet connection is
available; system fonts are used as fallbacks.
